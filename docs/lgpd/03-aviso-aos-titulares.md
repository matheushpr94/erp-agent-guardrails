# Modelo: aviso aos titulares (para o controlador publicar)

> A [EMPRESA] usa um assistente digital para consultar e organizar o próprio financeiro. Para isso, dados de cadastro e de cobrança (como nome, documento e valores) podem ser lidos pelo assistente, operado por [PRESTADOR]. Nenhuma alteração é feita sem a confirmação de uma pessoa responsável da [EMPRESA], e os dados não são usados para treinar modelos nem para outra finalidade. Para exercer seus direitos, fale com [CANAL DO CONTROLADOR].
